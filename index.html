Facts (do not upgrade to proofs)

  • QED at third order is a valid calculational tool; that does not by itself establish thrust.
  • Buhler’s public talks use 1st/2nd/3rd-order language (√α, α, α3/2). He has said the math is not closed. No peer-reviewed amplitude set is in this packet.
  • Hively EED is gauge-free: C = ∇·A + c−2 ∂tΦ. Modes TEM (C=0), SLW (B=0, E∥k, C≠0), SW (E=B=0, C≠0).
  • Only 1st- and 2nd-order dictionary rows are identities. All 3rd-order rows are HYP. Slider κ stands in for the missing QED³ matrix element.

SI conventions used here

u_C = C² / (2μ₀)
S_SLW = C E / μ₀

Unit trap: Hively 2019 often writes momentum density as −CE/μ (c=1). This ledger uses SI g = ε₀ C E throughout.
