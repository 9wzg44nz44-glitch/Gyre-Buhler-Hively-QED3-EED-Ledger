GYRE ledger notes

Buhler QED³ ↔ Hively EED — equations, dictionary, and pass/fail tests for the interactive instrument.

What this is

An interactive bookkeeping instrument, not a derivation of Exodus thrust. Buhler has not published closed third-order amplitudes. Every QED³ ↔ C map is tagged HYP.

SI conventions used in the code

Hively 2019 often writes momentum density as −CE/μ (c=1). The ledger uses SI:

C has the units of B (tesla)
u_C = C² / (2μ₀)
S_x = C E_x / μ₀
g_x = S_x / c² = ε₀ C E_x
energy source density = ρ C / (ε₀ μ₀) = ρ C c²
force density: J C and −∇(C² / 2μ₀)

EED equations (Hively / Woodside)

E = −∇Φ − ∂t A ,   B = ∇×A ,   C = ∇·A + c−2 ∂t Φ
∇×B − c−2 ∂t E − ∇C = μ₀ J
∇·E + ∂t C = ρ / ε₀
□C ≡ ∇²C − c−2 ∂t² C = −μ₀ (∂t ρ + ∇·J)

Modes

  • TEM: C=0, transverse E, B
  • SLW: B=0, E ∥ k, C ≠ 0 — energy and momentum
  • SW: E=B=0, C ≠ 0 — energy, no momentum

Isolated-system tests the sliders are for

  1. Set mode = TEM only, Γ = 0. Residual and F_net should both collapse (self-stress cancels).
  2. Set mode = SLW, η > 0, Γ > 0. F_net on the plates can be nonzero while P_matter + P_SLW stays near 0 if the outgoing wave is the reaction.
  3. Set mode = SW. Energy leaves (or stores) in C²/2μ₀ with no momentum channel. That cannot be an Exodus-style thrust carrier.
  4. Raise σ. TEM damps; SLW/SW do not (Hively no-skin: B=0 ⇒ no eddy current).

What would promote HYP → exact

  1. Buhler’s third-order matrix elements written in (A, Φ) without a Lorenz gauge dump of C.
  2. Identification of ⟨∂tρ + ∇·J⟩QED3 with a definite α3/2 coefficient, fixing κ.
  3. Same boundary-value problem solved once in EED and once from those amplitudes; term-by-term match of S_SLW and J C.
  4. Vacuum-chamber force linear in the predicted outgoing SLW momentum flux, not in ion wind.

Until (1)–(3) exist, the ledger is a conservation microscope, not a proof.
